# agendaApp

Een Java applicatie voor het beheren van agenda items, deadlines en evenementen.

## Project Structuur

Dit is een Java applicatie met de volgende componenten:
- `Calendar.java` - Agenda functionaliteit
- `Deadline.java` - Deadline beheer
- `Event.java` - Evenement beheer
- `Item.java` - Basis item klasse
- `Main.java` - Hoofdprogramma
- `Viewer.java` - Weergave functionaliteit

## Voor Collaborators

**Let op**: Deze repository gebruikt branch protection voor de `development` branch.

### Hoe bij te dragen

1. **Lees de collaboration guidelines**: Zie [CONTRIBUTING.md](CONTRIBUTING.md) voor gedetailleerde instructies
2. **Maak een branch vanaf development**: `git checkout -b feature/jouw-feature`
3. **Werk aan je feature en commit regelmatig**
4. **Push naar je eigen branch**: `git push origin feature/jouw-feature`
5. **Maak een Pull Request** naar de `development` branch via GitHub

### Belangrijke Regels

- ✅ Je kunt branches maken vanaf `development`
- ✅ Je kunt pushen naar je eigen feature branches
- ✅ Je kunt Pull Requests maken naar `development`
- ❌ Je kunt **NIET** direct pushen naar `development`
- 👤 Pull Requests moeten worden goedgekeurd door @erwinhenraat

Zie [CONTRIBUTING.md](CONTRIBUTING.md) voor volledige details.
